# CloudPulse

CloudPulse is a cloud-native application monitoring and incident
management platform being developed as a major Cloud and DevOps project.

## Current Status

Day 1 - Initial application development.

## Planned Technologies

- Python
- Flask
- PostgreSQL
- Docker
- GitHub Actions
- AWS
- Terraform
- Kubernetes
- Prometheus
- Grafana

## Project Goal

Build, containerize, test, deploy, monitor, and manage a cloud-native
application using modern DevOps practices.
