# The application dependencies live in app/requirements.txt, next to the code
# that imports them. This file exists so that a host which only looks at the
# repository root -- Render's native Python builder among them -- still finds
# what it needs.
#
#   pip install -r requirements.txt
#
# Render's Docker builder ignores this file and builds from ./app/Dockerfile
# instead, which is what render.yaml selects.
-r app/requirements.txt
